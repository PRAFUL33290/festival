Comment jouer ?

Clique sur les cases pour placer des sons sur les 8 temps. Appuie sur Play pour entendre ta boucle.

Le métronome donne le tempo. Le temps 1 est souvent le point de départ du rythme.

Pour les instruments mélodiques, choisis une note puis place-la dans la grille.

Essaie le mode Défi pour suivre une consigne et gagner un bonus.
